# ブランド（ロゴ・アイコン・色）

アプリ名は **Vocab Trainer** で確定（2026-08-02）。

## ロゴ — Coverage Grid

マス目 1 つが 1 語。左下から順に埋まっていき、白い 1 マスが「いま出題中の語」。
このアプリの中核である**語彙カバレッジの可視化**を、そのまま紋章にしている。

4 案（言語中立の抽象／V-Check／Card Flip／現行「語」の洗練版）を比較したうえで採用した。
決め手は 2 つ:

- **言語に依存しない**。英語・日本語の複数コースを 1 つのエンジンで回すので、
  特定言語の文字を紋章にすると、他コースの利用者から「自分のアプリ」に見えなくなる。
- **製品の中身と絵柄が一致している**。カバレッジが埋まっていく様子そのものなので、
  説明が後付けにならない。

弱点も分かったうえで採っている: **4×4 のままだと 32px 以下で模様に潰れる**。
そのため小サイズ専用に 3×3 へ間引いた compact 版を用意し、favicon はそちらを使う。

## 資産と使い分け

すべて `scripts/gen_brand_assets.py` が唯一の出所。**手で描き直さない。**
形や色を変えるときはスクリプトの定数を直して再生成する。

| ファイル | 形 | 使われる場所 |
|---|---|---|
| `public/pwa-512.png` / `pwa-192.png` | standard 4×4 | PWA マニフェスト（`purpose: any`） |
| `public/pwa-512-maskable.png` | standard 4×4・一回り小さい | PWA マニフェスト（`purpose: maskable`） |
| `public/apple-touch-icon.png` (180) | standard 4×4 | iOS のホーム画面追加 |
| `public/favicon.svg` / `favicon-32.png` / `favicon-16.png` | **compact 3×3** | ブラウザのタブ |
| `public/og.png` (1200×630) | standard＋ワードマーク | リンク共有時のカード |
| `src/brand/logo*.svg` | 各種 | マスター（配布・資料用。アプリは読み込まない） |
| `src/brand/Logo.tsx` | 各種 | アプリ内表示（起動画面・管理者画面） |

### なぜ maskable だけ別画像なのか

Android はアイコンの**内接円 80%（中心から半径 204.8/512）の外側を削る**。
`any` 用の画像を使い回すと 4 隅のマスが欠ける。maskable 版はマス全体を
対角の半分 201 < 204.8 に収めてあるので、円マスクでも欠けない。

### なぜ PNG に角丸を焼き込んでいないのか

iOS も Android も OS 側でマスクを掛ける。角丸を焼き込むと二重に丸められ、
角に濃紺の縁が残る。だから PNG は**角丸なしの正方形**にしている。

### 再生成

```bash
python scripts/gen_brand_assets.py          # 全部書き出す
python scripts/gen_brand_assets.py --check  # 差分があるかだけ見る（CI 向け）
```

## 色

アプリ本体の `src/design/themes.css` / `src/index.css` のトークンをそのまま使う。
**ロゴのために新しい色は作らない。**

| 役割 | トークン | ダーク | ライト |
|---|---|---|---|
| 地（PNG アイコンのみ焼き込み） | `--bg` | `#0b1120` | — |
| 習得済みのマス | `--accent` | `#6ea8fe` | `#2563eb` |
| 学習中のマス | `--accent` @ 45% | — | — |
| いま出題中のマス | `--logo-active` | `#e8edf7` | `#1e3a8a` |
| 未学習のマス | `--border` | `#263250` | `#c3cddd` |

`--logo-active` だけロゴ専用のトークンを立てている。ダークは白でよいが、
ライトで `--text`（ほぼ黒）を使うと青いマスの中で 1 マスだけ「穴」に見えたため、
**同じ青系のまま最も濃い段**に置いて濃さの階段を続けている。

アプリ内のロゴ（`Logo.tsx`）はこれらのトークンを参照しているので、
テーマを切り替えるとロゴもそのまま追従する。濃紺の地を焼き込んであるのは PNG だけ。

## 確認方法

`#brand` を開くとロゴ確認画面が出る（`#design` / `#tones` と同じ内部プレビュー）。
サイズ別の縮小・ロックアップ・起動画面・書き出し済み PNG・色の一覧が 1 ページに載っている。
右上のトグルでライト/ダークを両方見ること。

## OGP について

`index.html` に og:image を入れてあるが、**本番は Cloudflare Access の内側なので
外部のクローラーは取得できない**（リンクを SNS に貼ってもカードは出ない）。
社内で URL を共有したときや、将来公開する場合に備えて用意してある。
